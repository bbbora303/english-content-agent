# 롤플레이 B형 교과서 이미지 인식 정확도 개선 — 별도 AI 대화용 작업 프롬프트

> 이 문서는 **저작 도구(content-agent) 대화**가 아니라, 롤플레이 B형 교과서 지면의 다양한
> 레이아웃을 조사/학습하기 위한 **별도 Claude 대화**로 넘길 지시문입니다. 그 대화의 결과물을
> 다시 이 프로젝트로 가져와 `lib/analyzePrompt.js`(AI 이미지 분석 프롬프트)를 보강하는 데
> 쓸 예정입니다.

## 배경

저작 도구는 사용자가 업로드한 교과서 페이지 이미지를 Claude API(비전)로 분석해서, 어떤 콘텐츠
유형인지 판별하고(`understand`/`roleplay`/`roleplay_b`) 텍스트를 추출합니다. 이 판별과 추출은
전적으로 `lib/analyzePrompt.js`의 프롬프트 지시문 + 몇 개의 few-shot JSON 예시에 의존합니다
(별도로 모델을 재학습/파인튜닝하는 구조가 아닙니다 — Claude API를 그대로 호출하는 구조라,
정확도를 높이는 유일한 방법은 프롬프트 지시문과 예시를 더 정교하게 만드는 것입니다).

롤플레이 B형은 understand/롤플레이 A형과 달리 **교과서 지면의 레이아웃 자체가 다양한 것으로
파악**되고 있습니다. 지금 프롬프트는 "표 퀴즈 없이 여러 상황(장면)과 짧은 대화가 나열된 구조"
정도의 일반적인 설명과, "제목이 Look and Talk / Think and Talk이면 우선 B형으로 판단"이라는
규칙, 그리고 예시 1개만 갖고 있어 실제 다양한 지면에서 오판정할 가능성이 있습니다.

## 중요 — 반드시 실제 이미지를 넣고 진행해 주세요

이 리서치는 **실제 롤플레이 B형 교과서 지면 이미지를 최대한 다양하게 이 대화에 직접 첨부**해서
진행해야 효과가 있습니다. 이미지 없이 "롤플레이 B형은 대략 이런 구조다"라는 추상적 설명만으로
결과를 만들면, 지금 `lib/analyzePrompt.js`에 이미 있는 일반론적 설명과 크게 다르지 않은 내용이
나올 가능성이 높습니다. 장면 개수·배치·대사 길이·제목 표현이 다른 실물 지면들을 최대한 많이
모아서 하나씩 실제로 판정/추출해보고, 거기서 드러나는 구체적인 오판정 패턴을 잡아내는 것이
목적입니다.

## 요청하는 작업

1. **첨부한 각 이미지를 실제로 분석**해서, 장면이 몇 개인지, 화자·대사·해석이 무엇인지 직접
   판정/추출해 보고, 아래 출력 스키마에 맞는 JSON으로 만들어 보세요.
2. **이미지들 사이에서 발견되는 레이아웃 패턴을 분류**해 주세요. 예: 장면이 2개인 경우/4개인
   경우, 장면 이미지가 위·왼쪽·흩어져 배치된 경우, 장면마다 대사가 1줄인 경우/여러 줄인 경우,
   제목이 다른 표현으로 변형된 경우 등.
3. **판정 기준(현재는 "표 퀴즈 없음 + 가로로 넓은 대화 + 멀티 상황 이미지" 또는 제목 키워드
   매칭)에서 실제로 헷갈렸거나 애매했던 경계 사례(edge case)를 짚어 주세요** — 예를 들어 롤플레이
   A형과 헷갈릴 수 있는 지면, understand와 헷갈릴 수 있는 지면이 있다면 그 구분 포인트를 명확히
   해주세요.
4. **(가장 중요) 최종 결과물은 아래 "현재 프롬프트 원문"을 대체할 수 있는, 바로 붙여넣기
   가능한 완성된 텍스트로 정리해 주세요.** 분석 노트만 주시면 제가 다시 문장으로 옮기는 과정에서
   뉘앙스가 달라질 수 있으니, 아래 원문과 같은 형식(번호 매긴 지시문 + JSON 예시)으로 직접
   고쳐 써 주시면 이 프로젝트에 그대로 반영하기 가장 쉽습니다.

## 현재 프롬프트 원문 (교체 대상, `lib/analyzePrompt.js`의 9번 항목 + 관련 JSON 예시)

```
2. 표 퀴즈가 없고 단지 가로로 넓은 역할극 대화 스크립트와 멀티 상황 이미지가 존재한다면 'roleplay_b'(롤플레이 B형)로 설정하세요. 또한 최상단 제목이 "Look and Talk" 또는 "Think and Talk"이면(대소문자·띄어쓰기 변형 포함) 레이아웃이 다소 다르게 보이더라도 우선적으로 'roleplay_b'로 설정하세요.
...
9. [Roleplay_b(B형)인 경우] 표 퀴즈 없이, 여러 개의 개별 상황(장면)이 나열되고 각 장면마다 그에 딸린 짧은 대화(보통 A/B 한두 마디)가 붙어 있는 구조입니다. 이미지 좌표는 추출하지 마세요(장면 이미지는 저작 도구에서 자동으로 잘라내지 않고 사용자가 직접 업로드합니다) — 대신 텍스트만 정확히 장면 단위로 나누는 데 집중하세요:
   - 화면에 보이는 장면(상황) 개수만큼 views 배열 항목을 만드세요(x_percent 등 좌표 필드는 넣지 마세요). 장면이 몇 개인지는 실제 지면에 보이는 것을 세어 판단하고, 임의로 4개로 맞추지 마세요.
   - 그 장면에 속한 대화(보통 짧은 A/B 대사 한두 줄)만 그 항목의 'eng' 배열에 speaker/sentence/kor로 추출하세요. 장면과 대화의 대응 관계를 헷갈리지 말고, 각 장면(이미지가 있다면 그 이미지 바로 아래나 옆)에 붙어 있는 대화만 그 장면 것으로 간주하세요.
   - 장면 구분 없이 대화 스크립트 하나만 넓게 존재하는 경우(장면이 뚜렷하게 구분되지 않는 경우)에는 views 배열에 항목 1개만 넣고, 전체 대화를 그 안의 eng 배열에 순서대로 추출하세요.

[Roleplay_b 예시 - 표 퀴즈 없이 장면 2개 + 각 장면마다 짧은 대화가 나열된 경우 (좌표 없이 장면별 대사만 분리)]
{ "contentType": "roleplay_b", "letter": "B", "title": "Think and Talk", "instruction": "짝과 함께 제시된 표현과 의미를 활용하여 대화를 나누어 봅시다.", "views": [ { "originalInfo": "장면 1", "eng": [ { "speaker": "A", "sentence": "I'm feeling under the weather.", "kor": "몸이 좀 안 좋아." } ] }, { "originalInfo": "장면 2", "eng": [ { "speaker": "A", "sentence": "Look at that backpack. It looks really cool!", "kor": "저 배낭 좀 봐. 정말 멋지다!" } ] } ] }
```

위 원문을 참고해서, 실제 이미지 분석으로 발견한 내용을 반영한 **개선된 버전**(지시문 문장 + 예시 1개 이상, 다양한 레이아웃을 커버하려면 예시를 여러 개로 늘려도 됨)을 만들어 주세요.

## 현재 저작 도구가 기대하는 출력 스키마 (참고용)

```json
{
  "contentType": "roleplay_b",
  "letter": "B",
  "title": "Think and Talk",
  "instruction": "짝과 함께 제시된 표현과 의미를 활용하여 대화를 나누어 봅시다.",
  "views": [
    { "originalInfo": "장면 1", "eng": [ { "speaker": "A", "sentence": "...", "kor": "..." } ] },
    { "originalInfo": "장면 2", "eng": [ { "speaker": "A", "sentence": "...", "kor": "..." } ] }
  ]
}
```

**참고**: 씬 이미지 좌표(x_percent 등)는 더 이상 추출하지 않습니다 — 씬 이미지는 교과서 원본에서
자동으로 잘라내지 않고, 저작 도구 안에서 사용자가 직접 업로드하는 방식으로 결정되었습니다
(교과서 지면에 콘텐츠 이미지가 아예 없는 경우도 있기 때문). 그래서 이 리서치는 **텍스트(장면 개수,
화자, 대사, 해석) 추출 정확도**에만 집중하면 됩니다.

## 결과물을 이 프로젝트로 가져올 때

바로 붙여넣기 가능한 텍스트(위 4번 항목)를 받으면, 저작 도구 대화에서 `lib/analyzePrompt.js`의
9번 지시문과 JSON 예시를 그 내용으로 교체/보강하겠습니다. 레이아웃 패턴 분류나 경계 사례 메모도
함께 주시면 왜 그렇게 고쳤는지 이해하는 데 참고하겠습니다.
