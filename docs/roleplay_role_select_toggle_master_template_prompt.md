# 롤플레이 A~C형 마스터 템플릿 — 역할 선택 버튼 재클릭 시 선택 해제 안 되는 문제

> 이 문서는 **저작 도구(content-agent) 대화**에서 제보받은 내용을, 실제 마스터 템플릿
> (`view0X.js`/`view0X.html`, 롤플레이 A~C형)에서 확인·수정하기 위해 **마스터 템플릿 대화**로
> 넘기는 작업 지시문입니다. 이 문서를 그 대화에 그대로 붙여넣고, 문제가 되는 실제
> `view0X.html`(스크립트 포함)과 `view0X.js`/`view0X.css`를 함께 전달해주세요.

## 배경

저작 도구 사용자가 실제 학습 콘텐츠(롤플레이 A~C형)를 사용하던 중, 화면에 있는 "역할 선택"
버튼(학생이 A 역할 또는 B 역할 중 자신이 맡을 역할을 고르는 버튼으로 추정)에서 다음 문제를
제보했습니다:

- A 역할 또는 B 역할을 한 번 선택하면 정상적으로 선택 상태가 됨.
- 그런데 **이미 선택된 역할 버튼을 다시 클릭해도 선택이 해제되지 않음.**

## 확인 필요 — 저작 도구(App.jsx) 쪽 코드가 아님

이 "역할 선택" 버튼은 저작 도구(`src/App.jsx`)의 편집 화면에는 존재하지 않는 UI입니다.
App.jsx에는 대사 작성 시 화자(A/B)를 지정하는 `<select>` 드롭다운만 있고, 이는 저작자(콘텐츠
제작자)가 대본을 쓸 때 쓰는 편집용 UI라 이번 제보(학습자가 실제 콘텐츠를 이용하며 겪는 문제)와는
무관합니다. 따라서 원인이 될 만한 코드가 이 리포지토리에는 없고, 실제 `view0X.js`의 역할 선택
버튼 클릭 핸들러를 확인해야 원인 파악이 가능합니다.

## 요청 사항

1. 역할 선택 버튼의 클릭 핸들러를 찾아, 클릭 시 상태를 어떻게 관리하는지 확인해주세요
   (예: `selectedRole`류 변수 + 클래스 토글 방식인지, 아니면 다른 방식인지).
2. 이미 선택된 역할을 다시 클릭했을 때 **선택이 해제**되도록(토글 방식) 수정해주세요.
   - "해제된 상태"가 이 콘텐츠에서 어떤 의미를 가져야 하는지(예: 오디오 재생 대상이 전체 역할로
     돌아가는지, 단순히 버튼 강조 표시만 사라지는지)는 실제 로직을 보고 판단해주시면 됩니다.
3. 반대로 A 역할이 선택된 상태에서 B 역할을 클릭하는 등 **다른 역할로 전환하는 기존 동작**은
   지금처럼 정상 동작해야 합니다 — 이번 수정은 "같은 버튼 재클릭 시 해제" 케이스만 추가하는
   것이지, 기존 전환 동작을 바꾸는 것이 아닙니다.
4. 이 버튼이 A~C형 중 어느 유형(들)에 공통으로 쓰이는 컴포넌트인지, 아니면 유형별로 각각 구현이
   다른지도 확인해주시면 저작 도구 쪽에서 유형별 차이를 이해하는 데 도움이 됩니다.

## 참고

- 저작 도구 쪽 코드 변경은 없습니다 — 이 문제는 전적으로 마스터 템플릿(런타임 학습 화면) 쪽
  이슈로 확인됩니다.
