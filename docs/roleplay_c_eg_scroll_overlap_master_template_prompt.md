# 롤플레이 C형 — e.g. 배지와 대사 스크롤 영역 겹침 수정 요청 — 작업 프롬프트

> 이 문서는 **저작 도구(content-agent) 대화**에서 C형 캔버스를 실제 마스터 템플릿 값대로
> 구현하다가 발견한 레이아웃 겹침 문제를, **마스터 템플릿(view01.js/view01.css) 대화**로
> 넘기는 작업 지시문입니다. CLAUDE.md 5-5(저작 도구와 마스터 템플릿은 서로 다른 코드베이스)에
> 따라 관심사를 분리했습니다. 이 문서를 그 대화에 그대로 붙여넣고, 실제 C형 `view01.js`/
> `view01.css` 파일과 함께 전달하면 됩니다.

## 문제

C형은 A/B형과 달리 `.btn-eg`(e.g. 배지)가 대사 박스(`.role-play-script`) **바깥이 아니라 안쪽
우상단**에 위치합니다(이전에 전달받은 CSS 기준 `left:1064px, top:250px`, 대사 박스는
`left:156px, top:237px, width:968px, height:376px`). 이 좌표를 그대로 계산해보면:

- 대사 박스의 텍스트 콘텐츠 영역은 좌측 패딩(30px)만 빼면 오른쪽으로 거의 박스 끝(약 1094px
  지점)까지 뻗어나갑니다.
- `.btn-eg`는 `left:1064px`에서 시작(폭 45px, 끝은 1109px)하므로, **텍스트 콘텐츠 영역과 거의
  겹치는 x축 구간**에 위치합니다.
- 대사가 길어서 스크롤이 생기는 경우(예: 화살표 분기형처럼 한 페이지에 4턴 이상 들어가는 경우),
  **첫 줄 대사 텍스트가 배지 바로 아래/뒤로 지나가면서 배지와 겹쳐** 보입니다. 스크롤바도 같은
  우측 구간에 렌더링되므로 같이 겹칩니다.

A/B형은 `.btn-eg`가 대사 박스 **바깥 위쪽**(`top:210px`, 박스는 `top:256px`부터 시작)에 있어서
애초에 겹칠 수 없는 구조인데, C형만 박스 안쪽으로 배지가 재배치되면서 이 문제가 새로 생긴
것으로 보입니다.

## 저작 도구 쪽 임시 대응 (참고용)

저작 도구 캔버스에서는 대사 콘텐츠 영역의 우측 패딩을 기존 10px에서 70px로 늘려서(배지 폭
45px + 여유 15px + 기존 여백), 텍스트가 배지 구간 앞에서 줄바꿈되도록 임시 처리했습니다. 다만
이건 저작 도구 미리보기용 근사 조치이고, **정확한 수치와 방식은 실제 마스터 템플릿 CSS를
직접 조정하는 쪽이 기준**이 되어야 합니다.

## 요청

아래 중 적합한 방식으로 겹침을 해결해 주세요 (레이아웃 담당자 판단에 맡깁니다):

- **(안 1) 텍스트 영역에 우측 여백 확보**: `.role-play-script`(C형 버전)의 우측 padding을
  늘려서, 대사 텍스트/스크롤바가 `.btn-eg` 영역(대략 x:1064~1124, 박스 기준 우측 끝에서
  약 60px 구간) 앞에서 줄바꿈되도록 하세요.
- **(안 2) 배지 위치 재조정**: 텍스트 영역과 겹치지 않는 위치(예: 박스 바깥 우상단, A/B형처럼)로
  `.btn-eg`를 옮기는 방법도 가능합니다. 다만 이 경우 저작 도구 쪽에서 참고했던 원래 좌표(첨부
  이미지 기준 배지가 박스 안쪽에 있는 디자인)와 달라지므로, 실제 의도된 디자인이 무엇인지
  먼저 확인 부탁드립니다.
- 어느 방식이든, **대사가 길어져 스크롤이 필요한 경우까지 실제로 스크롤해보면서 겹침이 없는지
  확인**해 주세요(짧은 대사 1~2턴만으로는 스크롤이 안 생겨서 문제가 안 보일 수 있습니다).

## 확인 후 처리

수정된 좌표/CSS를 받으면, 저작 도구(content-agent) 쪽에서 캔버스의 임시 패딩 값(70px)을
실제 확정값으로 교체하겠습니다.
